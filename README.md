# Work Hub — واجهة تفاعلية (Prototype)

واجهة تفاعلية (Front-end prototype) لمنصة **Work Hub** لإدارة المشاريع والعملاء والموردين والفواتير لوكالات التسويق الرقمي، مبنية حسب مواصفات الـ MVP.

الواجهة تدعم RTL بالكامل، مبنية بـ React + TypeScript + Tailwind CSS، وتستخدم بيانات تجريبية (mock data) في الذاكرة لمحاكاة عمليات الإنشاء/التعديل دون الحاجة لباك-إند.

## التشغيل محليًا

```bash
npm install
npm run dev
```

## الأدوار المتاحة (للعرض التجريبي)

من شاشة الدخول يمكن اختيار الدخول كأحد الأدوار الثلاثة، أو التبديل بينها لاحقًا من القائمة أعلى يمين الشاشة:

- **المالك / المدير**: وصول كامل لكل الشاشات (العملاء، المشاريع، الموردون، الفواتير، الإعدادات).
- **مدير المشاريع**: إدارة المشاريع والموردين والفواتير، وعرض العملاء.
- **عضو الفريق**: عرض وتحديث المهام المسندة فقط.

## الشاشات المنفذة

تسجيل الدخول، لوحات تحكم لكل دور، العملاء (قائمة وتفاصيل)، المشاريع (لوحة Kanban قابلة للسحب والإفلات وتفاصيل المشروع)، المهام، الموردون (قائمة وتفاصيل)، الفواتير (قائمة وتفاصيل مع حساب الضريبة)، والإعدادات.

## البنية التقنية

- React 19 + TypeScript
- Tailwind CSS v4
- React Router
- lucide-react للأيقونات
